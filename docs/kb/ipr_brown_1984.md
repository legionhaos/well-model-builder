# Методика расчета индикаторной кривой притока Composite IPR (Brown, 1984)

## 1. Назначение и физический смысл
Модель Composite IPR (Brown, К.Е., 1984 / Petrobras) описывает приток многофазной смеси (нефть + вода + растворенный газ) из пласта на забой скважины с учетом обводненности продукции $wct$.

## 2. Основные допущения и уравнения
* При забойном давлении $P_{wf} \ge P_b$ (выше давления насыщения): в пласте движется однофазная жидкость, действует линейный закон фильтрации Дарси с коэффициентом продуктивности $J$ (`pi`):
  $$q_t = J(P_{res} - P_{wf})$$
* При забойном давлении $P_{wf} < P_b$: нефтяная фаза выделяет газ и подчиняется нелинейной кривой Вогеля (Vogel, 1968), а водная фаза продолжает течь линейно.
* Результирующее давление смеси рассчитывается геометрическим сложением:
  $$P_{wf}(q) = (1 - F_w) P_{wf,o}(q) + F_w P_{wf,w}(q)$$
  где $F_w = wct / 100$.
* Дебит смеси $q_t$ находится аналитически через положительный корень квадратного уравнения:
  $$q_t = \frac{-C + \sqrt{C^2 - 4B^2 D}}{2B^2}$$
* Граничные случаи:
  - При $wct = 100\%$ или $P_b = 0$: строго линейная модель Дарси.
  - При $wct = 0\%$: чистая квадратичная кривая Вогеля.
  - При $P_{wf} = P_{res}$: дебит строго равен 0.
