# Composite IPR: методическая справка

## Область применения

В узловом анализе IPR описывает зависимость забойного давления `p_wf` от дебита жидкости `q_liq`. Для однофазного притока при давлении выше давления насыщения используется линейная продуктивность: `q = pi * (p_res - p_wf)`. При притоке ниже давления насыщения нефтяная составляющая становится нелинейной; суммарную жидкостную кривую нельзя в общем случае получить простым арифметическим смешением дебитов нефти и воды.

## Контракт расчётного сервиса

Входные давления задаются в атм, дебит жидкости — в м³/сут, `wct` — в процентах, `pi` — в м³/(сут·атм), а число точек задаёт дискретизацию кривой. Для воспроизводимой сетки используется равномерный диапазон `p_wf` от 1 атм до `p_res`; крайняя точка соответствует нулевому дебиту. Граничные случаи `pi=0`, `wct=0`, `wct=100`, `pb=0` и `pb>=p_res` нужно обрабатывать явно.

## Проверки

Проверяйте конечность чисел, неотрицательность дебита и невозрастание `q_liq` при росте `p_wf`. Валидация некорректных параметров должна возвращать JSON с HTTP 4xx, а не HTML или пустое тело.

Источник: внутреннее методическое описание проекта Well Model Builder; основная литература по composite IPR — Brown, *The Technology of Artificial Lift Methods*, 1984. Конкретные расчётные уравнения должны соответствовать утверждённому ТЗ и реализации сервиса.
